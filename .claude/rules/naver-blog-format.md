# Naver Blog Format Rules

## Purpose

이 규칙은 Moduus Studio 블로그 초안(Markdown)을 네이버 블로그에 최적화된 형식으로 변환할 때의 기준을 정의한다.

---

## 1. 제목 규칙

- **길이**: 30~35자 권장 (네이버 검색 노출 최적)
- **필수 포함**: 메인 SEO 키워드 1개 이상
- **선호 패턴**: 숫자 포함 / 문제의식 표현 / 운영자 관점
- **금지**: `#` 마크다운 헤딩 문자 포함 금지

좋은 예:
```
243명이 참여한 아이디어 경진대회, 사전 준비가 성패를 갈랐다
신청폼부터 팀 매칭까지, 행사 전날에 이미 준비해 들어갔다
```

---

## 2. 본문 첫 단락 (C-rank 핵심)

- **200자 이내**에 메인 키워드 포함 필수
- 숫자·장면·문제의식 중 하나로 시작
- Blockquote(`>`) 제거 후 본문 첫 단락으로 통합하거나 재작성

---

## 3. 본문 변환 기준

| 원본 Markdown | 네이버 변환 |
|---|---|
| `## 섹션 제목` | `**섹션 제목**` (굵은 텍스트) |
| `> 후킹 문장` | 첫 단락 본문으로 통합 (꺾쇠 제거) |
| 인라인 코드 (`` ` ``) | 일반 텍스트로 변환 |
| 마크다운 표 (`|---|`) | 들여쓰기 없는 줄글로 변환 |
| `---` 구분선 | 빈 줄 2개로 대체 |
| `[확인 필요]` 등 표기 | 그대로 유지 |

- **단락 간격**: 단락 사이 빈 줄 2개 (가독성·에디터 호환)
- **강조**: 핵심 수치·역할 표현은 `**굵게**` 유지

---

## 4. 제외 항목 (본문에 포함 금지)

블로그 초안에서 아래 섹션은 네이버 게시 본문에 넣지 않는다.

- 썸네일 문구
- SEO 키워드 표
- 태그 목록 (별도 태그 입력란으로 분리)
- 재사용 자산 (제안서·포트폴리오·회사소개서 문장)
- 자체 퇴고 결과
- 확인 필요사항 메모

---

## 5. 태그 규칙

- **개수**: 10~20개 권장
- **형식**: 쉼표 구분 (`태그1, 태그2, 태그3`)
- **순서**: 메인 키워드 → 롱테일 키워드 → 연관 키워드
- **출처**: 블로그 초안의 SEO 키워드 섹션에서 추출 + 네이버 검색 최적화 태그 보강
- **금지**: `#` 해시태그 기호 사용 금지 (네이버 태그 입력란은 쉼표 구분)

---

## 6. 이미지 삽입 가이드

실제 이미지 파일 생성은 이 에이전트의 역할이 아니다.
이미지가 들어가야 할 위치와 권장 유형만 안내한다.

- **최소 7장 권장** (네이버 C-rank 이미지 가중치 + 과정 전달력)
- 사용 가능한 사진이 많을수록 행사 과정 단계마다 삽입해 흐름이 느껴지도록 배치한다
- 권장 삽입 위치 (단계별):
  - S2(배경/기획) 뒤 — 모집 포스터 또는 SNS 홍보 게시물
  - S3(운영 구조) 초반 — 오리엔테이션 현장 사진
  - S3(운영 구조) 뒤 — 팀 구성·역할 배치 슬라이드 또는 문서
  - S4(현장 운영) 내 — 현장 장면 2~3장 (로비 전경, 운영 스태프 활동, 참가자 접수 등)
  - S5(성과) 뒤 — 성과 수치 슬라이드 또는 인포그래픽
  - S5 시상 설명 뒤 — 시상 장면 사진
  - S7(마무리) 뒤 또는 글 끝 — 단체사진

---

## 6-1. 본문 이미지 앵커 (자동 삽입용)

`naver_publish.py`가 이미지를 본문 위치 근처에 자동 삽입할 수 있도록, 본문 안에
**이미지 앵커**를 남긴다. 앵커는 사람이 아니라 스크립트를 위한 위치 신호다.

- **문법(풀형)**: `[[IMG:파일명|alt=설명|caption=캡션]]`
- **최소형**: `[[IMG:파일명]]` (alt·caption 생략 가능)
- **예시**: `[[IMG:img-poster-sns.jpg|alt=공식 포스터|caption=인스타 공식 포스터]]`

배치 규칙:
- 앵커는 **본문 독립 줄**에 둔다(문단 중간에 끼우지 않음). 위쪽 문단 = 삽입 권장 위치.
- 파일명은 `.claude/artifacts/naver/images/[slug]/` 안의 실제 파일명과 일치해야 한다.
- 앵커 순서 = 본문 등장 순서 = 업로드 순서.

처리 규칙(스크립트 계약):
- **성공 시**: 앵커는 이미지로 치환되어 **화면 텍스트로 남지 않는다**.
- **실패 시**(파일 없음·업로더 실패): 앵커 자리에
  `[이미지 수동 삽입 필요: 파일명 / 권장 위치]` 텍스트로 치환한다. 본문은 훼손하지 않는다.
- **8MB 초과**: 이번 MVP에서는 업로드를 **스킵하고 경고**하며 위 수동 삽입 안내로 치환한다
  (자동 리사이즈는 별도 옵션으로 분리).
- 앵커가 하나도 없는 본문은 기존과 동일하게 동작한다(회귀 없음).

> `## 6. 이미지 삽입 가이드` 표는 **사람 검토용으로 계속 유지**한다. 앵커는 그 표의
> "삽입 권장 위치"를 본문 실제 위치로 옮긴 기계가독 신호다.

---

## 7. 발행 체크리스트

변환 완료 파일에는 반드시 아래 체크리스트를 포함한다.

```
[ ] 제목 35자 이내 확인
[ ] 본문 첫 200자에 메인 키워드 포함 확인
[ ] 이미지 최소 3장 삽입 (별도 진행)
[ ] 태그 10개 이상 입력
[ ] 맞춤법 검사 완료
[ ] 사람이 최종 확인 후 발행
```

---

## 8. 저장 경로

- 저장 위치: `.claude/artifacts/naver/[slug]-naver.md`
- 예: `knu-idea-bridge-2026-naver.md`
- 자동 발행 금지 — 발행은 항상 사람이 확인 후 직접 진행

---

## 9. 스타일 규약 (잘나가는 블로그 플레이북)

naver.md 본문은 `docs/blog-winning-patterns.md`를 기본 적용한다. **모든 글 필수 요소:**

- **제목**: 메인 키워드 맨 앞 + 숫자 + 32자 이내
- **첫 문장 후킹**: 숫자·장면·문제의식·따옴표로 시작(두괄식)
- **상단 콜아웃 2개**: 핵심요약 박스(수치 3개) + 정보 카드(📅 일시 · 📍 장소 · 👥 규모 · 🤝 주관)
- **이모지 소제목** 5개 이상(📌🗂🙋📈🏛💡…), 지도형·두괄식
- **문단 2~3문장** + 불릿(•/✔) 적극
- **형광펜** `[형광]...[/형광]`으로 핵심 수치·문구 강조(5곳+)
- **이미지 혼합**: 대표 포스터/배너(개별) 최상단 + 콜라주(1×2) + 슬라이드, 총 8장+, 중복 0
- **본문 1,800~3,500자**(순수), 메인 키워드 3~5회
- **개선점 1스푼**(아쉬운 점) — 신뢰도
- **용역사 마무리**: "이 행사를 운영한 팀"으로 모드어스 스튜디오 명시 + 소프트 문의 CTA (과장 금지)
- **재사용 자산**(포트폴리오/제안서 문장)은 아카이빙용으로 blog_draft에 보존

## 10. 품질 게이트 (발행 전 필수)

```bash
python3 scripts/blog_score.py .claude/artifacts/naver/[slug]-naver.md
```
- **90점 이상 → 발행 권장.** 미만이면 "개선 여지" 항목을 보완 후 재채점.
