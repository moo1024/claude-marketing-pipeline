# SNS Winning Patterns — 인스타그램 · Threads 플레이북

> 딥리서치(2026-07-09, Meta 공식 문서 + 한국 레퍼런스 계정 조사) 기반.
> Moduus 운영사례형 콘텐츠를 인스타 캐러셀 + Threads로 이식할 때의 "잘되는 포인트".
> 채점·변환 규칙은 `.claude/rules/sns-format.md`가 정본.

## 0. 채널 전략 한 줄

- **계정 = B2B 운영 실적 진열장.** 팔로워 수보다 "발주처 담당자가 봤을 때 신뢰되는 피드"가 목표.
- 네이버 블로그가 검색 유입·상세 서사 담당 → 인스타는 **시각적 증빙**, Threads는 **운영자 목소리 + 블로그 유입**.
- 한국 행사 대행사들의 후기형 인스타 콘텐츠는 미성숙 → 정제된 후기 캐러셀만으로 차별화 가능.

## 1. 인스타 캐러셀 — 후기형 공식 (기본형, 8~10장, 4:5 세로)

| 슬라이드 | 역할 | 포인트 |
|---|---|---|
| 1 | **숫자 후킹 표지** | 12단어 이내. "243명이 참여한 ○○, 성패는 전날 결정됐다". 사진 배경 + 어두운 오버레이 |
| 2 | **핵심 수치 3개 카드** | 블로그 핵심요약 박스 이식. 트리플 훅 — 1~3장 각각이 독립 미끼 |
| 3 | **현장 베스트 컷** | 사진 1장 + 한 줄 캡션 |
| 4 | **행사 개요 정보 카드** | 📅 일시 · 📍 장소 · 👥 규모 · 🤝 주관 |
| 5~6 | **운영 설계 포인트 ①②** | "진행"이 아닌 **"설계"** 강조. 신청폼 구조·동선 분리 같은 방법론 |
| 7 | **성과·피드백** | 확인 수치만. `[확인 필요]` 등 미확인 표기는 캐러셀에서 **해당 수치 자체를 제외** |
| 8 | **개선점 1스푼** | 신뢰 장치. 블로그 §9와 동일 철학 — "다음엔 이렇게" |
| 9 | **이 행사를 운영한 팀** | 모드어스 스튜디오. 운영 설계 관점 한 문단 |
| 10 | **CTA + 저장 유도** | "다음 행사 기획 때 꺼내보세요" + 소프트 문의 |

**모집형 변형 (6장 압축):** 혜택 후킹 → 대상 → 내용 → 일정 → 혜택 상세 → 신청 CTA.

## 2. 캡션 공식 (인스타)

- **첫 줄 = 후킹** (더보기 접힘 전에 승부). 숫자/문제의식.
- 이후 3~6줄: 핵심 수치 + 운영 설계 요약 + "자세한 운영기는 프로필 링크(블로그)".
- 검색 키워드(행사명·기관명·행사 유형)를 캡션 본문에 자연스럽게 포함 — 인스타 검색이 캡션 텍스트를 색인.
- **해시태그 5개 이하** (2025.12 인스타 정책 권고). 메인 키워드 → 행사명 → 지역/기관 순.
- 본문 링크는 클릭 불가 → 링크 유도는 "프로필 링크" 또는 스토리로.

## 3. Threads 공식

**단발형 (기본):**
- 1줄 후킹(숫자/고백형) + 2~3줄 운영 인사이트 + 질문 or 네이버 블로그 링크.
- **300자 이내** 권장 (한도 500자). **토픽 태그 1개만**. 이미지 1~2장(4:5).
- Threads는 **본문 링크 클릭 가능** → 네이버 블로그 유입 통로로 사용.

**타래형 (심화):**
- 루트: 후킹 + 대표 사진 → 리플 2~4개: 운영 디테일·실패담·비하인드 → 마지막 리플: 성과 요약 + 블로그 링크.
- 리플 하나 = 하나의 디테일. 루트만 봐도 완결, 리플은 보너스.

**톤:** 기관 공지체 금지. **'모드어스 운영 담당자 개인' 화자** — "저는 이 행사에서 ○○을 제일 걱정했습니다" 식. (스픽·잡코리아 계정 패턴)

## 4. 타이밍·형식 참고

- 게시 골든타임: **8~9시 / 23시~1시** (Threads 기준, 참고치)
- 캐러셀은 릴스 대비 참여율·저장률 우위(저장률 약 2배). 릴스는 비팔로워 도달 3~5배 — 후기형은 캐러셀 중심, 릴스는 후순위 옵션.
- 저장 유도 문구("저장해두고 다음 기획 때 참고하세요")가 저장률에 직접 기여.

## 5. 카드 디자인 원칙

- **4:5 (1080×1350) JPEG 통일** — 인스타 API는 PNG 불가, 캐러셀은 첫 이미지 기준 일괄 크롭이므로 전 카드 동일 비율 강제.
- 핵심 텍스트는 **중앙 1:1 안전영역** 안에 배치 (그리드 썸네일 잘림 대응).
- 한글: `word-break: keep-all`, Pretendard. 표지 제목은 2줄 이내.
- 사진 배경 카드: 어두운 오버레이(40~60%) + 흰 텍스트.
- 텍스트 카드: 여백 크게, 카드당 메시지 1개. 글자로 채우지 말 것.

## 적용 체크리스트 (게시물마다)

- [ ] 슬라이드 1 제목: 숫자 포함 + 12단어 이내 + 2줄 이내
- [ ] 슬라이드 1~3 트리플 훅 (각각 독립 미끼)
- [ ] 수치는 확인된 것만 (미확인 수치는 캐러셀에서 제외)
- [ ] "운영 설계" 관점 슬라이드 최소 2장
- [ ] 개선점 1스푼 포함
- [ ] 모드어스 팀 소개 + 소프트 CTA
- [ ] 캡션 첫 줄 후킹 + 해시태그 5개 이하
- [ ] Threads 300자 이내 + 토픽 태그 1개 + 블로그 링크
- [ ] 전 카드 4:5 JPEG, 텍스트 안전영역 준수
