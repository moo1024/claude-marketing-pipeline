# Blog Winning Patterns — 잘되는 블로그 플레이북

> 다수 소스(네이버 C-rank/DIA, 상위노출·제목·가독성·스토리텔링 가이드) + 레퍼런스 블로그(바로랩·뤼미에르 체험단형)에서 추출한 "잘되는 포인트". Moduus 운영사례형 블로그에 적용.

## 1. 검색 로직이 보는 것 (C-rank + DIA)
- **C-rank**: 출처(블로그) 신뢰·전문성. 한 주제로 꾸준히 쌓을수록 유리.
- **DIA(Deep Intent Analysis)**: 문서의 **경험·정보성**과 **체류시간·완독률**을 점수화.
- 실무 시사점: **끝까지 읽히는 구조 = 랭킹**. 완독률↑ → 체류시간↑ → 상위노출.

## 2. 제목 (클릭 관문)
- **메인 키워드를 맨 앞에** 배치(검색엔진 가중치↑).
- **한글 32자 이내**(넘으면 … 잘림).
- **숫자 포함**("243명", "31개 팀") — 구체·신뢰·가독.
- 혜택/궁금증/문제의식 1가지. 과장 형용사는 공공·기관 톤에선 절제.

## 3. 서론 (이탈 방지)
- **후킹 첫문장**: 숫자·장면·문제의식·경험담으로 시작(스펙 나열 금지).
- **두괄식**: 결론/핵심을 앞에. 중요도 높은 순으로.
- 첫 문단 안에 메인 키워드 1회.

## 4. 본문 구조 (완독률)
- **소제목 = 지도**: 스캔만 해도 흐름이 보이게. 서술형·구체형 소제목.
- **문단 2~3문장(4~5줄 이내)** — 길면 끊어라.
- **리스트/불릿**으로 나열(문단으로 늘어놓지 말 것).
- **이미지로 텍스트 분절**(피로 완화). 사진 **6~13장+** 권장.
- 본문 **1,500~2,000자+**, 메인 키워드 **본문 3~5회** 자연 반복.

## 5. 이미지·레이아웃 (체류·가독)
- **대표 이미지**(썸네일)는 주제 직결 컷 — 우리 경우 **포스터/배너 최상단**.
- 사진 한 장씩 세로로 늘리지 말고 **콜라주(1×2/1×3)·슬라이드**로 묶기.
- **같은 성격끼리 그룹**(전경/등록/부스/네트워킹/시상), **중복 배제**.
- 캡션으로 맥락 부여.

## 6. 스타일 (스캔성·주목)
- **핵심요약 박스**(인용구) 상단 1개 — 수치 3개.
- **정보 카드**(📅일시 📍장소 👥규모 🤝주관).
- **이모지 소제목**(📌🗂🙋📈🏛💡) — 섹션 인지.
- **형광펜/굵게**로 핵심 수치·문구 강조(스캔 유도).
- **체크리스트 콜아웃**(✔) — 인사이트·요약.

## 7. 신뢰·설득 (브랜드/기관 톤)
- **스토리텔링**: 지향점 → 이유 → 차별점. "왜 이 행사가 필요했나"에서 출발.
- 장점 나열 대신 **근거·수치·장면**으로 증명.
- **솔직한 개선점** 1스푼(다음엔 이렇게) → 광고 느낌 제거, 신뢰↑.
- 발주처/기관 관점 효용을 명시(운영사례형의 차별점).

## 8. 마무리
- 결론 문단 또는 **재사용 인사이트**로 닫기.
- CTA는 기관 톤에 맞게 절제(문의/연계 안내 수준).

## 적용 체크리스트 (글마다)
- [ ] 제목: 메인 키워드 맨 앞 + 숫자 + 32자 이내
- [ ] 첫 문장: 숫자/장면/문제의식 후킹, 두괄식
- [ ] 상단: 핵심요약 박스 + 정보 카드
- [ ] 소제목: 이모지 + 지도형, 6~8개
- [ ] 문단: 2~3문장, 불릿 적극
- [ ] 대표 포스터/배너 최상단 + 콜라주·슬라이드 혼용(사진 8장+)
- [ ] 형광펜/굵게로 핵심 수치 강조
- [ ] 키워드 본문 3~5회
- [ ] 개선점 1스푼(신뢰)
- [ ] 미확인은 [확인 필요]
